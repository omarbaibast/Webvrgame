Deploying to GitHub Pages (100% Free)

Because this app operates entirely inside the browser using client-side JavaScript, Web Audio API, and TensorFlow.js, it requires **no backend server** and can be hosted directly on GitHub Pages for free.

  1. Create a new repository on GitHub (e.g., my-ai-voice-synth).
  2. Save this single HTML document as index.html on your computer.
  3. Upload or commit index.html to the root of your GitHub repository.
  4. Go to your repository Settings → Pages.
  5. Under Build and deployment, set the source Branch to main (or master) and folder to / (root).
  6. Click Save. In 1–2 minutes, your AI voice app will be live at https://<username>.github.io/<repo-name>/!
Microphone Permissions Note: Web Audio recording requires HTTPS. GitHub Pages automatically provides free SSL certificates, so microphone access will work perfectly.
