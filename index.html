Controls — PS4 DualShock 4, Keyboard, Touch & WebXR

PS4 DUALSHOCK 4 (GAMEPAD API)
  • Left Stick: Move Forward / Back / Left / Right
  • Right Stick: Look Left / Right / Up / Down
  • Cross (X): Jump
  • Circle (O): Cancel / Exit interaction or modal
  • Square: Interact / Place building
  • Triangle: Toggle World Map
  • L1 / R1: Prev / Next build item or option
  • L2 / R2: Secondary / Primary interaction
  • L3: Toggle Sprint
  • R3: Recenter pitch / view
